📷 Camera AI · Bird species model

Two real AI models run directly in your browser: one checks that the object is a bird, and a second tries to name its species from 525 trained bird categories. No API server address is needed.

The model is not guaranteed to know every bird in the world. It can still mistake similar species. The name and percentages are estimates, not proof.

AI model details

Bird detection: TensorFlow.js COCO-SSD (bird class). Bird species estimate: bird-species-classifier via Transformers.js; trained on 525 species. This is not Merlin, not BirdID and not a universal wildlife-identification model.
